Privacy Policy

AurumFlux AI, Inc. · Effective 20 September 2026

This policy covers the Atlassian Marketplace apps published by AurumFlux AI, Inc., including Issue Templates by AurumFlux for Jira Cloud, and the website aurumflux.co.

What the app stores

Issue Templates stores the template definitions you create — a template name, scope, category, an issue tree of issue-type names and summaries, optional descriptions, and variable names. It also stores a short record of each apply (the issue keys it created) so that a failed or repeated apply can be cleaned up or replayed instead of creating a second tree.

For templates you mark personal, the app stores your Atlassian account ID so that only you can see them. It stores no other personal data.

Where it is stored

All app data is held in Forge hosted storage (the Key-Value Store) inside Atlassian's infrastructure, in the region of your Atlassian site. The app is built on Forge and is eligible for Atlassian's Runs on Atlassian program: it makes no network calls to any server outside Atlassian, and no data leaves Atlassian's platform.

What the app reads

When you apply a template, the app calls the Jira REST API as you, using the permissions you already have, to read the target project's issue types and create-screen fields and to create the issues. It does not read issues, comments, or attachments it did not create.

What we do not do

  • We do not sell, share, or transfer app data to any third party.
  • We do not use app data for advertising, profiling, or training.
  • We do not receive a copy of your data — it stays in your site's Forge storage. AurumFlux can see aggregate usage metrics that Atlassian provides to app developers (invocation counts, error rates), which contain no issue content.

Deletion

Deleting a template removes it from storage immediately. Uninstalling the app removes all of the app's stored data for that site, per Atlassian's Forge data-retention behaviour.

Website

aurumflux.co is a static site served by GitHub Pages. It sets no cookies of its own and runs no analytics scripts. Payments, where offered, are processed by Stripe under Stripe's own privacy policy; we receive the name and email you provide at checkout and use them only to deliver what you bought.
