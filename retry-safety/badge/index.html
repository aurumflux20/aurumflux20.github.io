Retry-Safety badges

Every implementation named on the Retry-Safety Index can show a badge in its README. Each badge links to its own public row, so the claim is checkable by anyone, not asserted by the project.

Verified, battery run. We ran the ten-mode hostile-facilitator battery against a named release, end to end, and counted one settlement per purchase in every mode reached. The strongest tier.

Verified, code read. A line-by-line read of the settle, retry and signing paths found no double-charge seam. Weaker than a run, and labelled so.

Fixed. We reported a double-charge seam and the team shipped a fix. The row credits them with the time to fix.

Every badge is free. It describes the release and date on its row. If a later release changes the retry or settle path, ask us to re-check it at hello@aurumflux.co.
